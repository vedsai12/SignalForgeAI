# SignalForge AI

Transforming the Live Web Into Revenue Intelligence.

![SignalForge AI Banner](./public/banner.png)

## Overview

SignalForge AI is an autonomous GTM intelligence platform that continuously monitors competitors, buying signals, pricing changes, hiring trends, and market movements using AI agents powered by Bright Data infrastructure.

The platform transforms live web intelligence into:

* AI-generated battle cards
* competitor insights
* realtime alerts
* buying signals
* revenue intelligence

SignalForge AI helps enterprise sales, marketing, and revenue teams make faster and smarter decisions using real-time web intelligence.

# Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/signalforge-ai.git
cd signalforge-ai
```

---

# Install Dependencies

```bash
npm install
```

---

# Environment Variables

Create a `.env` file:

```env
OPENAI_API_KEY=
BRIGHTDATA_API_KEY=
DATABASE_URL=
REDIS_URL=
NEXT_PUBLIC_API_URL=
```

---

# Run Development Server

## Frontend

```bash
cd apps/web
npm run dev
```

## Backend

```bash
cd apps/server
npm run dev
```
